# זוז – מתקשרים ונוסעים

אתר תדמית והזמנות לשירות המוניות זוז (‎*8565 · וואטסאפ 058-4920004).

- קובץ יחיד: `index.html` (HTML/CSS/JS, בלי תלויות ובלי שלב בנייה)
- הזמנת נסיעה ופניות עסקיות נשלחות כהודעת וואטסאפ מוכנה
- אנימציית לוגו, סצנת לילה עם מוניות נוסעות ואנימציות גלילה
- מותאם לנייד ומכבד הגדרת "הפחתת תנועה"

## הרצה מקומית

פותחים את `index.html` בדפדפן, או:

```
python -m http.server 8000
```

## לפני עלייה לאוויר

- לאשר את שעות השבת (`CLOSE_FRI` / `OPEN_SAT` בקוד)
- להחליף את הלוגו שנבנה מחדש בקובץ הלוגו המקורי, אם רוצים
- לעדכן את הקישור לעמוד הפייסבוק
